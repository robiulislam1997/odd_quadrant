## Abstract
 Driving Automation Systems (DAS) are designed
      to operate only within a defined Operational Design Domain
      (ODD), which specifies the environmental, roadway, and
      traffic
      conditions under which the system can operate safely.
      However,
      existing driving datasets often include scenes outside a
      DAS?s
      ODD, which interfere with development. Removing these re-
      quires costly manual review since ODDs use vague or
      context-
      based terms such as ?heavy rain? or ?bright light.?
      Previous
      work has leveraged Large Language Models (LLMs) to resolve
      these nuances by connecting natural language descriptions
      with the visual sensor data of the scene, demonstrating
      near-
      human performance in data labeling; yet, plain use of LLMs
      is
      insufficient. Building on this idea, we introduce
      ODD-Quadrant,
      which uses spatially-grounded prompting to improve ODD-
      decision performance. ODD-Quadrant further introduces an
      automated refinement loop that analyzes incorrect
      predictions
      to iteratively refine prompts, extracting edge cases latent
      in
      existing human-labeled datasets, improving model
      consistency
      across iterations, and providing, as a final output, human-
      interpretable refined specifications resolving prior
      ambiguity.
      Our evaluations demonstrate that by using spatial prompting
      and automated refinement, ODD-Quadrant enhances the effi-
      ciency of detecting ODD compliance, showing improvements of
      up to 220% over manual approaches while doubling the
      failure
      identification over prior work, highlighting the
      significance of
      edge case refinement and the capacity to generalize to new
      data.
